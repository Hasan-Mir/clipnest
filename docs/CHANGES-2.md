# نسخه‌ی ۲ — تغییرها

## نمایش دقیق استایل (مثل CopyQ)
- کارت‌ها و پیش‌نمایش، **HTML اصلی کلیپ** (`HTML Format`) را رندر می‌کنند؛ پس‌زمینه، فونت، اندازه و فاصله‌ی خطوط VS Code عیناً دیده می‌شود. highlight.js حذف شد.
- امن‌سازی: HTML با `DOMParser` (بدون اجرای اسکریپت) parse می‌شود؛ script/iframe/event handler/لینک‌ها و بارگذاری منابع خارجی حذف می‌شوند. رندر داخل Shadow DOM است تا CSS برنامه‌ی مبدأ به UI نشت نکند.
- متن وب با رنگ تیره و بدون پس‌زمینه روی «کاغذ» روشن نشان داده می‌شود تا خوانا باشد.
- تنظیمات: «نگهداری استایل (HTML/RTF)» (خاموش = فقط متن ذخیره می‌شود)، «نمایش لیست: استایل اصلی / متن ساده»، و override برای هر Pinboard. در پیش‌نمایش و نوار جستجو هم دکمه‌ی جابه‌جایی بین دو حالت هست.

## کلید میانبر با Win
- میانبرهایی که `Win` دارند (مثل `Win+V`) با **hook کیبورد سطح پایین** مدیریت می‌شوند (`RegisterHotKey` برای آن‌ها شکست می‌خورد). کلید Win با چک‌باکس انتخاب می‌شود چون ویندوز آن را قبل از صفحه می‌گیرد. دکمه‌ی «Use Win+V» در تنظیمات هست.

## بقیه
- **زبان:** انگلیسی، فارسی (RTL) و ۷ زبان دیگر با تغییر آنی و منوی سینی سیستم سفارشی.
- **جابه‌جایی کارت‌ها:** درگ با ماوس یا `Alt+↑/↓`. ترتیب با کلید کسری ذخیره می‌شود (فقط یک ردیف نوشته می‌شود).
- **Erase history:** در تنظیمات، فوتر پنجره، منوی راست‌کلیک تب Clipboard و منوی سینی سیستم (همیشه با تأیید).
- **جستجو:** متن کامل (تا ۱۰۰ هزار کاراکتر هر آیتم) + تحمل غلط املایی (۱ اشتباه برای ۴–۶ حرف، ۲ برای ۷+). نتایج دقیق اول، فازی بعد. دکمه‌ی `~` حالت subsequence، دکمه‌ی `.*` حالت Regex.
- **Import/Export:** خروجی فشرده از کل تاریخچه؛ ورودی به‌صورت ادغام غیرمخرب (آیتم‌های تکراری رد می‌شوند). بکاپ‌های روزانه هم با همین دکمه قابل بازیابی‌اند. خروجی/ورودی تنظیمات هم هست.
- **قوانین خودکار:** شرط (برنامه، نوع، regex) ← عمل (ثبت نشود، انتقال به Pinboard، برچسب، فقط متن ساده، trim، حذف خودکار، اجرای اکشن سفارشی).
- **تنظیم هر Pinboard:** حداکثر آیتم، سبک نمایش، حالت پیست و Pinboard فعال.
- **آیکون واقعی برنامه‌ها:** یک‌بار از exe استخراج و در دیتابیس ذخیره می‌شود.
- دیتابیس نسخه‌ی ۱ به‌طور خودکار migrate می‌شود.
