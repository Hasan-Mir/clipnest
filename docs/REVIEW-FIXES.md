# نتیجه‌ی بررسی و تغییرهای اعمال‌شده

هر مورد با کد واقعی تطبیق داده شد و اصلاح گردید.

## اعمال شد (معتبر)
| # | مورد | اصلاح |
|---|---|---|
| 1.1 | `React.memo` در `Card` هندلرهای کهنه (stale closure) را نگه می‌داشت | هندلرهای پایدار که از طریق ref به آخرین closure فوروارد می‌کنند |
| 1.2 | کپی مجدد همان متن، این بار با استایل، فرمت‌های HTML/RTF را دور می‌ریخت | `insert_clip` برای آیتم تکراریِ دارای استایل، فرمت‌ها و `has_rich` و `lang` را به‌روز می‌کند |
| 1.3 | Paste Queue: کلید Ctrl فیزیکی توسط keyup مصنوعی رها می‌شد | کلید Ctrl نگهداشته‌شده حفظ می‌شود و دوباره فشرده/رها نمی‌شود |
| 1.4 | زیرمنوی Transform/Actions بیرون از پنجره‌ی ۴۰۰px می‌افتاد | زیرمنو `fixed` است و نسبت به لبه‌های پنجره (راست/چپ/بالا/پایین) جابه‌جا و clamp می‌شود |
| 1.5 | فیلتر برنامه فقط `app_name` را می‌دید و کلمات متن را می‌بلعید | کلمه‌ی شبیه نام برنامه با نام *یا* exe *یا* محتوا مطابقت داده می‌شود |
| 1.7 | کاراکتر NUL انتهایی `vscode-editor-data` عملیات parse را خراب می‌کرد | صفرهای انتهایی قبل از parse حذف می‌شوند |
| 1.8 | ویرایش درجا پرچم حساس را پاک می‌کرد و متن خالی می‌پذیرفت | تشخیص حساس دوباره اجرا می‌شود، متن خالی رد می‌شود، `expires_at` همگام می‌شود، Preview با ردیف تازه sync می‌شود |
| 1.9 | کلیک روی مقدار رنگ با `navigator.clipboard` به‌عنوان کپی جدید ثبت می‌شد | فرمان `copy_text` در Rust (با `self_seq`) |
| 1.10 | کدپیج فارسی در اکشن‌ها، پروسه‌ی بدون kill، و quoting خراب | `chcp 65001`، `cmd /S /C "…"` با `raw_arg`، `taskkill /T /F` هنگام timeout |
| 1.11 | `explorer /select` با مسیر دارای فاصله/ویرگول | `raw_arg` با مسیر داخل کوتیشن |
| 1.12 | race در ذخیره‌ی تنظیمات هنگام تایپ | ذخیره با debounce ۲۵۰ms و نادیده گرفتن echo رویداد خودمان |
| 1.13 | کلید تکراری در Queue؛ ارسال Ctrl+V هنگام باز کردن از tray | کلید `id-index`؛ بدون target فقط کپی می‌شود |
| R1 | بکاپ با قفل DB و خواندن کل فایل در RAM | قفل فقط برای `VACUUM INTO`؛ فشرده‌سازی gzip جریانی بیرون از قفل |
| R2 | `rename` بدون `sync_all` | `write_atomic` با fsync برای settings و بکاپ |
| R3 | محاسبه‌ی موقعیت با DPI مانیتور قبلی | پس از جابه‌جایی اندازه دوباره اندازه‌گیری و پنجره دوباره جایگذاری می‌شود |
| R4 | جستجو: ستون‌های سنگین قبل از متادیتا | ستون‌های سنگین (`preview/search/plain/thumb`) به انتهای جدول رفتند + debounce ۴۵ms هنگام تایپ |
| R5 | COM در STA بدون `CoUninitialize` | MTA + `CoUninitialize` پس از آزادسازی اشیاء |
| تست | هیچ تستی نبود | تست‌های واحد برای `normalize`، رنگ/لینک، داده‌ی حساس، NUL، heuristic کد (`cargo test`) |
