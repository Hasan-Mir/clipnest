## 2. Pre-Apply Checks, Divergences & Rejected Findings

- **Pre-Apply Verification Results:**
    - `tauri-plugin-global-shortcut` Thread Affinity: Inspected `tauri-plugin-global-shortcut-2.4.1` and `global-hotkey-0.8.0` in Cargo cache. Windows global shortcut handler is invoked synchronously from `global_hotkey_proc` via `WM_HOTKEY` messages on the **main UI thread**. In `src-tauri/src/lib.rs:163`, `on_shortcut` acquires `st.queue_sc.lock()`. Meanwhile, `unregister` and `register` call `run_on_main_thread` and synchronously block (`rx.recv()`). Holding `queue_sc.lock()` in background threads across `register` or `unregister` creates a fatal AB-BA deadlock. Resolved by dropping `queue_sc` lock before unregistering and rewriting `sync_intercept`.
    - `db::insert_clip` Callers: Inspected all callers across `packages/core/src` and `src-tauri/src`. None call `insert_clip` within an existing SQLite transaction or savepoint; wrapping in `TransactionBehavior::Immediate` is completely safe.
    - `run_transfer` Visibility: Confirmed zero callers outside `src-tauri/src/queue.rs`. Signature changed to private `fn` accepting `guard: &mut BusyGuard`.

- **Corrections / Adaptations Made to External Directives:**
    - `PATCH-04` Schema Correction: External review proposed inserting into `clip_formats(clip_id, name, mime, bytes)` with `f.mime, f.bytes`. The live schema and struct is `clip_formats(clip_id, fmt_id, name, size, data)`. Preserved live schema columns, `StoredFormat` fields, and `CASE WHEN ?1 IS NOT NULL THEN ?2 ELSE kind END` in clip update.
    - Regression Test 5 `CliIo` Property: External review suggested `readStdin: async () => 'hello world'`, but the TypeScript `CliIo` interface defines `stdin?: string | (() => Promise<string>)`. Supplying `stdin: 'hello world'` avoided test hang on `process.stdin`.

- **Rejected Findings / False Positives:**
    - None rejected; all 15 findings and the deadlock risk were validated against live code and resolved.
