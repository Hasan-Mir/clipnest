## 1. Applied Fixes

| Patch / Issue ID | Severity | File(s) & Symbol(s) | Root Cause & Summary of Fix |
| ---------------- | -------- | ------------------- | --------------------------- |
| `PATCH-01` | High | `src-tauri/src/queue.rs` (`sync_intercept`, `sync_intercept_with`) | In Round 06's `sync_intercept`, `st.queue_sc.lock()` was held across the `unregister()` call in the `else` branch, re-introducing the UI thread AB-BA deadlock and unregistering the winning thread's shortcut. Extracted `sync_intercept_with` ensuring the lock is never held during `register()` or `unregister()` and verifying that if `want` flips to false while registering, the lock is dropped before calling `unregister()`. |
| `PATCH-02` | High | `packages/core/src/ipc.rs` (`import_json_bundle`) | Re-importing a JSON backup with a matching clip hash called `db::insert_clip` unconditionally, triggering an `UPDATE` that silently unmasked sensitive clips, cancelled `expires_at`, overwritten `app_name`/`app_exe`, and modified timestamps. Added an existence pre-check (`SELECT 1 FROM clips WHERE hash=?1`) to skip existing clips before `insert_clip`. |
| `PATCH-03` | High | `src/popup/Preview.tsx` (`Preview`) | Exiting inline edit mode (`Escape`, `Save`, or `Cancel`) unmounted the focused `<textarea>`, leaving `document.activeElement` as `document.body` and breaking subsequent keyboard navigation because global key handling is suppressed while preview is open. Added `wasEditingRef` and an effect to refocus `root.current` (`.preview`). |
| `PATCH-04` | Medium | `src/popup/Overlays.tsx` (`ContextMenu`) | When `SubMenu` closed via mouse hover over a sibling item or scroll on `.menu`, `setOpenSub(null)` unmounted `.menu.sub` without refocusing `menuElRef.current`, dropping focus to `document.body` and breaking keyboard navigation. Added `prevOpenSubRef` to restore focus to `menuElRef.current` whenever `openSub` becomes `null`. |
| `PATCH-05` | Medium | `packages/core/src/db.rs` (`with_write_tx`, `assign_category_with_pin`, `erase_history`, `move_item`, `merge_from`) | SQLite in WAL mode with read-then-write transactions using `SAVEPOINT` or `BEGIN` (deferred) failed with `SQLITE_BUSY_SNAPSHOT` (error 517, bypassing `busy_timeout`) when another connection committed between the read and write. Added `with_write_tx` acquiring `BEGIN IMMEDIATE` when `conn.is_autocommit()` is true, and updated `merge_from` to use `BEGIN IMMEDIATE`. |
| `PATCH-06` | Medium | `src/lib/highlightMatch.tsx` (`isSafeHighlightRegex`, `findMatchSpans`) | Synchronously evaluating nested-quantifier regex queries (e.g. `(a+)+b`) in JavaScript's backtracking engine caused exponential ($O(2^n)$) catastrophic backtracking, freezing the WebView2 UI thread. Added `isSafeHighlightRegex` to reject nested quantifiers, backreferences (`\1`..`\9`), and patterns exceeding 256 characters before creating a `RegExp`. |
| `PATCH-07` | Medium | `packages/cli/src/index.ts` (`runCli`) | Catch-all `else` branches in TypeScript CLI command families (`category`, `queue`/`basket`, `rule`, `action`, `config`) forwarded unknown subcommands to IPC or offline fallback, exiting with `EXIT_OFFLINE` (`4`) instead of `EXIT_USAGE` (`2`). Added explicit checks to reject unknown subcommands with `EXIT_USAGE` for parity with native Rust CLI argument parsing. |
