# 📋 ClipNest — مدیر کلیپ‌بورد سریع، هوشمند و خصوصی برای ویندوز

**ClipNest** یک مدیر کلیپ‌بورد فوق‌سریع و کاملاً آفلاین برای **ویندوز ۱۰ و ۱۱** است که سادگی و زیبایی رابط کاربری Copywren و Notion را با قدرت و امکانات پیشرفته CopyQ ترکیب می‌کند.
Fast, private clipboard manager & file collector for Windows (Tauri v2 · Rust · Win32 · React · SQLite).

---

## ✨ امکانات کلیدی (Key Features)

- ⚡ **عملکرد آنی و مصرف منابع ناچیز:** هسته‌ی بومی Rust + SQLite در حالت WAL با `synchronous=FULL`؛ هر کپی در همان لحظه با `fsync` روی دیسک ذخیره می‌شود و حتی در صورت قطع ناگهانی برق از دست نمی‌رود.
- 🎨 **نمایش و پیست دقیق استایل (Original Style / Rich HTML):** کدها و متن‌های کپی‌شده از VS Code، Word و مرورگرها دقیقاً با همان فونت، رنگ و پس‌زمینه داخل Shadow DOM امن نمایش داده می‌شوند؛ همراه با دکمه‌ی سریع `Aa` برای تغییر آنی بین نمایش با استایل و متن ساده.
- 🧺 **صف پیست دوحالته و سبد فایل و تصویر (Paste Queue & Drop Basket):**
  - **Queue Mode:** چندین متن یا آیتم را کپی کنید و با زدن پیاپی `Ctrl+V` به ترتیب (FIFO یا LIFO) پیست کنید.
  - **Drop Basket (Collector Mode):** در پوشه‌های مختلف ویندوز یا صفحات وب بچرخید و فایل‌ها (`Ctrl+C` / `Ctrl+X`) و تصاویر مرورگر را جمع کنید (کپی‌های متنی به‌طور هوشمند نادیده گرفته می‌شوند)؛ سپس با یک کلیک همه‌ی آن‌ها را در پوشه‌ی مقصد یا فلش USB پیست یا منتقل کنید (حذف فایل مبدأ در حالت `CUT` فقط پس از تأیید کامل کپی و بررسی دقیق حجم فایل در مقصد انجام می‌شود).
- 🔍 **جستجوی چندحالته و هایلایت هوشمند:** جستجوی آنی در کل متن، عنوان، نام برنامه و تگ‌ها با پشتیبانی از کلمات کلیدی نوع (`image`, `code`, `link`, `file`, `color`, `text`)، حالت فازی (`~`)، عبارت باقاعده (`.*`)، تحمل غلط املایی و هایلایت دوحالته (رنگ متن به سبک VS Code و ماژیک پس‌زمینه) بدون شکستن اتصال حروف فارسی.
- 📌 **Pinboard ها و حالت Pinboard فعال:** تب‌های رنگی نامحدود با قابلیت Drag & Drop به سبک Claude، تنظیم حالت نمایش و حالت پیست مجزا برای هر Pinboard، و قابلیت انتخاب «Pinboard فعال» تا کپی‌های جدید مستقیماً وارد همان تب شوند.
- 🛡️ **حریم خصوصی و محافظت در برابر اسکرین‌شات:** محافظت آنی پنجره‌ها با `SetWindowDisplayAffinity` (مستطیل مشکی یا کاملاً نامرئی در ضبظ صفحه و اسکرین‌شات)، تشخیص خودکار داده‌های حساس (شماره کارت بانکی با الگوریتم Luhn، کلیدهای API، توکن‌های JWT و کلیدهای خصوصی) با تار کردن و حذف زمان‌بندی‌شده، و احترام به پرچم برنامه‌های مدیریت رمز عبور.
- 🌍 **چندزبانه (۹ زبان زنده دنیا + فونت وزیرمتن):** پشتیبانی کامل از فارسی (`RTL` با فونت `Vazirmatn`)، انگلیسی، عربی، اسپانیایی، چینی، روسی، آلمانی، فرانسوی و ترکی با معماری ماژولار در `src/lib/locales/`.
- ⚙️ **تنظیمات پیشرفته به سبک VS Code و Notion:** منوی چرخ‌دنده‌ی بازنشانی برای هر تنظیم، بازنشانی هر بخش، جستجوی سریع در تنظیمات با `Ctrl+F`، دراپ‌داون‌های سفارشی، Tooltip ها و منوی سینی سیستم (System Tray) مدرن.

## 🚀 پیش‌نیازها و اجرا (Build & Run)

1. **Windows 10 (2004+)** یا **Windows 11** (همراه با WebView2)
2. **[Rust](https://rustup.rs)** (نسخه‌ی `stable-x86_64-pc-windows-msvc`، ۱.۷۷ به بالا)
3. **Visual Studio Build Tools** با گزینه‌ی «Desktop development with C++»
4. **Node.js ≥ 18**

```powershell
npm install
npm run tauri dev       # اجرای محیط توسعه
npm run tauri build     # ساخت فایل نصاب در src-tauri\target\release\bundle\nsis\
```

اگر هنگام کامپایل ماژول UI Automation خطا داد، می‌توانید بدون آن کامپایل کنید:
```powershell
npm run tauri build -- --no-default-features
```

## ⌨️ کلیدهای میانبر (Keyboard & Mouse Shortcuts)

| عملکرد | کلید / ماوس |
|---|---|
| باز کردن پنجره‌ی اصلی | `Win+V` (پیش‌فرض؛ در تنظیمات قابل تغییر به `Alt+V` و غیره) |
| پیست با استایل / متن ساده (یا مسیر فایل) | دوبار کلیک یا `Enter` / `Shift+Enter` (`Ctrl+Enter` = با استایل) |
| انتخاب تکی / انتخاب بازه‌ای / انتخاب چندتایی | تک‌کلیک / `Shift+Click` (یا `Shift+↑/↓`) / `Ctrl+Click` |
| پیست سریع کارت‌های قابل‌مشاهده | `Ctrl+1` … `Ctrl+9` |
| جابه‌جایی ترتیب کارت‌ها | کشیدن با ماوس (Drag & Drop) یا `Alt+↑/↓` |
| پیش‌نمایش و ویرایش درجا (با ذخیره‌ی خودکار) | `Space` (یا `F3`) · `Ctrl+E` |
| جابه‌جایی بین تب‌ها و Pinboard ها | `←` `→` یا `Tab` یا `Ctrl+[ ]` |
| فوکوس روی نوار جستجو | `Ctrl+F` |
| سنجاق کردن آیتم به بالای لیست | `Ctrl+P` |
| تغییر نام / برچسب‌ها / بازرس فرمت‌ها | `F2` / `Ctrl+T` / `Ctrl+I` |
| ادغام چند آیتم انتخاب‌شده | `Ctrl+M` |
| صف پیست و سبد فایل (Paste Queue / Drop Basket) | `Ctrl+Alt+Q` |
| تغییر حالت متن ساده‌ی سراسری | `Ctrl+Alt+P` |
| باز کردن تنظیمات | `Ctrl+,` |
